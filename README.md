# KüyTranscribe

Веб-сервис для расшифровки сольной записи домбры в ноты, двухструнную
табулатуру, MIDI и MusicXML.

## Возможности

- распознавание аудио локально в браузере через Spotify Basic Pitch;
- строи D3–G3, C3–G3 и D3–D4;
- табулатура, нотный лист и таблица нот;
- воспроизведение исходной записи;
- экспорт MIDI, MusicXML и PDF через печать;
- поддержка MP3, WAV, M4A, OGG и FLAC.

## Локальный запуск

```bash
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

Проект настроен для Vercel через `vercel.json`. Модель Basic Pitch хранится
в `public/model` и загружается приложением с того же домена.

## Ограничения MVP

Лучший результат дают чистые записи одной домбры без голоса и фоновой музыки,
длительностью до 10 минут.
